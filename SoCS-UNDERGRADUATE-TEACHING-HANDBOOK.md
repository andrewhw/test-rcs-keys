# Exams

## Creating Exams

You will need to create both an exam and a grading rubric.  The rubric is required even if you will be grading the exam yourself because in the event of a student petition for Grade Reassessment:

* [Undergraduate Calendar: VIII. Undergraduate Degree Regulations and Procedures -- Grade Reassessment](https://calendar.uoguelph.ca/pdf/Undergraduate%20Calendar.pdf#page=70)


It is important that the exam is well proofed, and that as much as possible there are no errors in the exam.


## Running the Exam

* [Undergraduate Calendar: VIII. Undergraduate Degree Regulations and Procedures -- Examinations](https://calendar.uoguelph.ca/pdf/Undergraduate%20Calendar.pdf#page=66)


### Instructions for Exams

Note these words in the Calendar:

> Including all instructions regarding the examination on the
> examination paper, i.e., writing on every other line, writing on the
> right hand pages of the book. No verbal instructions can be made
> at the examination hall with the exception of corrections to printed
> instructions and material.

This implies that:

* All instructions to students need to be written on the exam itself.  If exam instructions are provided to students in advance, such as in class, as an announcement, etc. then any such instructions **have** to be mirrored with text on the exam, and the text on the exam supersedes any such prior announcement.

	* For clarity, if there is any ambiguity or correction provided by the exam relative to an earlier announcement, it is best to directly address this ambiguity in the text on the exam

* Instructions on the exam are, by definition, the correct way to write the exam.  That is, if there is any conflict between written instructions on the exam and any other information, then the instructions written on the exam itself are the definitive instructions (see "Corrections" below).

* When giving "complete M out of N questions", be sure to give an unambiguous strategy for what will happen if more than M questions are answered.  Recommended text:

	*Answer M of the N questions in this section.  Only the first M answers you provide will be graded.  If you begin an answer and do not want it to be graded, be sure to cross this answer out from the exam.*


* Do not needlessly specify the same directions more than once -- it is very easy to accidentally introduce a contradiction by doing this.


### Corrections to the Exam Text

If an error is discovered **prior to the exam sitting**, and there is time to address this by reprinting, it is best to provide a printed update:

* if the class is small, it is likely it is best to reprint the entire exam with the correction
* if the class is large, printing a "corrections" sheet is best.  This should be laid out on top of the exam, and ideally printed on a contrasting colour sheet.


If an error is discovered during the examination sitting, it can be addressed through an announcement.  Such an announcement is inevitably a disturbance to the students writing the exam, however so it is best to consider how to proceed.  Fundamentally, our strategy must be that a student is not disadvantaged by a error on the exam.

* First, note that as per the Instructor's Responsibilities outlined in [Undergraduate Calendar: VIII. Undergraduate Degree Regulations and Procedures -- Examinations](https://calendar.uoguelph.ca/pdf/Undergraduate%20Calendar.pdf#page=66), the only verbal instructions that can be made once the exam starts are to provide "corrections to the printed instructions or material."

* If the examination error introduces an ambiguity, consider whether the student's interpretation of the ambiguity can be detected during grading, and the appropriate grade awarded.  If so, this avoids the need for an announcement altogether.

* If a more serious problem has arisen, try and express the correction with the greatest clarity as possible:

	* a short announcement is best.  Repeat the full announcement at least twice

	* ideally, the announcement can be provided in writing as well, such as by displaying the text of the announcement on a screen visible to all the students.  As some students may miss the announcement (especially in large exam halls) this gives a reference throughout the remaining exam time

	* if a question can be salvaged by providing a single missing fact or simple clarification, this is a reasonable way to proceed

	* if clarification requires more complexity than a short statement can provide, it is best to simply remove the question from the exam.  Simply announce that this is the case (e.g. "There is an error with one of the questions, and it will be removed.  The following questions will not be graded: question 2 in Version A, question 17 in Version B, etc.").  Again, providing written reference is best.
